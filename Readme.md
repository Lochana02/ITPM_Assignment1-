# Sinhala Transliteration Testing using Playwright

## 📌 About This Project

This project was done for **IT3040 – ITPM Assignment 1**.

The main idea is to check how well the given web application converts Singlish text into Sinhala. I tested different types of inputs and focused mainly on cases where the system gives incorrect results.

Website used for testing:
https://www.pixelssuite.com/chat-translator

---

## 🛠 What I Used

* Python (3.11 / 3.12)
* Playwright
* OpenPyXL
* Chrome / Chromium browser

## ⚙️ How to Set It Up

### 1. Clone the repository

git clone https://github.com/Lochana02/ITPM_Assignment1-.git
cd ITPM_Assignment1-


### 2. Install required packages


pip install -U pip
pip install playwright openpyxl
playwright install


---

## ▶️ How to Run

Run this command in the project folder:

python test_automation.py --excel "Assignment 1 - Test cases.xlsx" --url "https://www.pixelssuite.com/chat-translator" --wait-ms 5000 --type-delay-ms 80 --slow-mo-ms 200 --save-every 1 --keep-open


## ⚙️ What the Script Does

* Reads the test cases from the Excel file
* Sends each Singlish input to the website
* Gets the Sinhala output
* Compares it with the expected answer
* Updates the Excel file with:

  * Actual Output
  * PASS or FAIL

---

## ⚠️ Important Things to Remember

* Don’t fill the “Actual Output” or “Status” columns manually — the script will handle that
* Make sure the Excel file is in the same folder as the script
* You need an internet connection to run the test
* If the website is down, the results might fail (that’s normal)

---

## 📊 Results

After running the script, you can open the Excel file and see:

* The output generated by the system
* Whether each test case passed or failed
